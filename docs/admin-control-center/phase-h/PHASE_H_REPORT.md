# Phase H Completion Report: Durable Leads Collection & Form Persistence

**Date:** 2026-10-09  
**Status:** COMPLETED & VERIFIED (SEALED)

## 1. Executive Summary

Phase H permanently closes **Defect D2** (Form Submissions Dropped Without Durable Lead Persistence).

Previously, incoming project inquiries validated client-side and server-side, but if an external webhook was unconfigured, the submission resulted in no database row and zero durable persistence.

With Phase H executed under the approved **Master Plan Amendments (B & C)**:
1. Every validated form submission durably commits to PostgreSQL before a success response is returned to the visitor.
2. An autogenerated, human-readable Reference ID (e.g. `SL-YYYYMMDD-XXXX`) is produced and returned.
3. Secondary notifications (webhooks/email) run post-persistence: failure of external delivery never loses the lead or returns false errors to the user.
4. Permanent V1 Lead Workflow statuses are established: `NEW`, `CONTACTED`, `QUALIFIED`, `WON`, `LOST`, `SPAM`.
5. An authorized CSV export endpoint (`GET /api/leads/export`) allows lead extraction with UTF-8 BOM (for Excel) and formula injection protection.
6. Zero PII is leaked in public bundles, client telemetry, or build artifacts.

## 2. Inventory of Delivered Components

### 1. Payload Collection
- **File:** `src/collections/Leads.ts`
- **Slug:** `leads`
- **Fields:**
  - `reference`: Unique indexed human reference ID (`SL-YYYYMMDD-XXXX`).
  - `status`: Select with V1 statuses (`NEW` default, `CONTACTED`, `QUALIFIED`, `WON`, `LOST`, `SPAM`).
  - `name`: Client name.
  - `company`: Company / entity name.
  - `phone`: Normalized Saudi phone number (`+966XXXXXXXXX`).
  - `email`: Optional client email.
  - `channel`: Preferred contact channel (`whatsapp`, `call`).
  - `timeline`: Expected project timeline (`now`, `quarter`, `later`, `unsure`).
  - `mode`: Submission mode (`brief`, `quick`).
  - `lands`: Selected capability lands JSON array.
  - `goal`: Client goal description.
  - `notes`: Client notes.
  - `consent`: Explicit privacy consent confirmation.
  - `locale`: Submission locale (`ar`, `en`).
  - `campaign`: Attribution and marketing UTM data.
  - `ipHash`: Privacy-preserving SHA-256 IP hash prefix for rate tracking.
  - `internalNotes`: Array of internal team notes (`text`, `author`, `createdAt`).
- **RBAC:**
  - Read: Requires `leads.read` permission (Admin, Marketing, Super Admin).
  - Update: Requires `leads.update` permission (Admin, Super Admin).
  - Create: Denied via public API (handled securely by route handler via Local API with `overrideAccess: true`).
  - Delete: Requires Super Admin authority (`roles.manage`).
- **Hooks:**
  - `afterChange`: Logs `lead_status_changed` in `audit_events`.

### 3. API Route Handler
- **File:** `src/app/api/brief/route.ts`
- **Invariant:** A visitor receives `{ ok: true }` **only** if the lead row is durably stored in PostgreSQL.
- **Secondary Delivery:** Webhook dispatch runs after DB persistence and is completely non-blocking.
- **Audit Logging:** System automatically records `lead_created` for each submission.

### 4. Secure CSV Export
- **File:** `src/app/api/leads/export/route.ts`
- **Access:** Requires `leads.export` permission.
- **Security:** Formula injection prevention (prefixes values starting with `=`, `+`, `-`, `@`, `\t` with `'`).
- **Localization:** Prepend `\uFEFF` UTF-8 BOM for immediate compatibility with Arabic Excel.
- **Auditing:** Records `lead_exported` event with total exported count.
