# PHASE E — الصفحات والأقسام والقوالب المكتوبة (Pages · Sections · Typed Blocks)

> حالة المرحلة: **منفّذة ومختبَرة** — التقرير النهائي في `PHASE_E_REPORT.md`.
> النطاق: §0–§99 من تفويض المرحلة. **لا عمل على Phase F قبل قرار المالك.**

## ماذا أصبح ممكنًا للمشرف غير التقني؟

| القدرة | الحالة |
| --- | --- |
| تعديل نصوص الصفحات بالعربية والإنجليزية مستقلًا | ✅ الصفحتان لا تتأثران عند الكتابة في الأخرى (§1) |
| مسودة لا يراها الزائر + معاينة داخلية قبل النشر | ✅ `/ar/preview?path=/…` بزر «معاينة» في المحرّر |
| النشر لكل لغة على حدة، أو اللغتين معًا للصفحات الأساسية | ✅ `POST /api/pages/:id/publish` |
| إلغاء النشر (رجوع للنص الاحتياطي أو 404) | ✅ `POST /api/pages/:id/unpublish` |
| إخفاء قسم أو قصره على لغة | ✅ `enabled` + `localeVisibility` |
| إعادة ترتيب الأقسام | ✅ ترتيب المصفوفة في المحرّر |
| استعادة نسخة سابقة | ✅ تبويب الإصدارات + `POST /api/pages/:id/restore` |
| إنشاء صفحة جديدة برابط جديد بدون مبرمج | ✅ `/ar/{slug}` و `/en/{slug}` |
| حماية هوية الصفحة الأساسية ومنع تغيير مسارها | ✅ `systemKey` + `RESERVED_SEGMENTS` |
| سجل تدقيق لكل عملية نشر/رفض/استعادة | ✅ `audit_events` |

## ملفات المرحلة (وثائق §97)

1. `PAGES_MODEL.md` — نموذج الصفحة: الهوية، الروابط، الحالات لكل لغة، المسودات.
2. `BLOCK_REGISTRY.md` — السجل الواحد للأقسام: المفاتيح، المتغيرات، الوسائط، الحدود.
3. `PUBLISHING_AND_VALIDATION.md` — بوّابة النشر الواحدة ورسائل الرفض.
4. `PREVIEW.md` — المعاينة الآمنة: التفويض، التخزين المؤقت، منع الفهرسة.
5. `VERSIONING.md` — الإصدارات والاستعادة.
6. `CACHE_AND_AUDIT.md` — وسوم الكاش وإبطالها، وأحداث التدقيق.
7. `MIGRATION_AND_EQUIVALENCE.md` — نقل الصفحات الحالية وإثبات التكافؤ، وما تبقّى.
8. `EDITOR_GUIDE_AR.md` — دليل المشرف بالعربية (خطوة بخطوة).
9. `PHASE_E_REPORT.md` — التقرير النهائي (§98).
