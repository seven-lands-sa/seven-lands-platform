# المعاينة الآمنة للمسودات

المسار: `/{locale}/preview?path=/…` — يفتحه زر **معاينة** في محرّر الصفحة، أو يدويًا.

## الضمانات

| الضمان | كيف تُنفّذ |
| --- | --- |
| تفويض مزدوج | الوكيل (proxy) يرد **404 حقيقي** لمن لا يملك كوكي جلسة إدارية؛ ونقطة البيانات `GET /api/pages/preview-data` تعيد الفحص على صلاحية `pages.read`. كوكي قديم أو مُلفّق = لا شيء يظهر. |
| لا رمز في الرابط أو HTML | لا يوجد توكن معاينة مشترك؛ الجلسة نفسها هي التصريح، والكوكي `HttpOnly` لا يُطبع في الصفحة. |
| مسودة لا منشور | القراءة من أحدث **مسودة** باللغة المطلوبة، والمسارات العامة لا تستدعي هذا المسار إطلاقًا. |
| لا فهرسة | `noindex, nofollow, noarchive` من الوكيل + وسوم الصفحة + غياب تام عن `sitemap.xml` + `robots.txt` يمنع `/*/preview`. |
| لا تخزين مؤقت | كل شيء `no-store` (الاستجابة والصفحة)، والقراءة عبر `fetch` بلا تخزين — تحت `cacheComponents` أي قراءة لا يعرفها Next كقراءة ديناميكية تُخبز في الهيكل المُجهّز مسبقًا؛ قِيست المشكلة ثم أُصلحت ولا تُفعّل cacheComponents عالميًا. |
| وسائط خاصة تبقى خاصة | نفس مُحلّل الوسائط العام: ملف خاص = بديل مرئي، لا تسريب رابط. |

## الحالة المنشورة تُعرض بوضوح

شريط المعاينة يذكر المسار واللغة وحالة النشر («النسخة المنشورة» / «مسودة غير منشورة») ورابط «عرض الصفحة العامة»، فهو شريط إداري لا جزء من التصميم العام.

## الدليل

`verify-runtime.log`: زائر بلا جلسة → `404` على `/ar/preview` و`/en/preview`؛ بجلسة مشرف → `200`
وشريط معاينة ونص الهيرو؛ تعديل مسودة → يظهر في المعاينة فقط، ولا يظهر في الموقع العام.
